# Khắc phục lỗi Cache không hoạt động trong Spring Boot (Mô phỏng bằng Python)\n\n## Giới thiệu\nBài tập này minh họa cơ chế hoạt động của Spring Cache, giải thích nguyên nhân thiếu `@EnableCaching` dẫn đến cache không hoạt động, và cung cấp giải pháp mô phỏng logic caching tương đương bằng Python.\n\n## Các chức năng đã làm\n- Phân tích nguyên nhân thiếu cấu hình cache AOP Proxy.\n- Xây dựng lớp UserService mô phỏng logic tra cứu Database và kiểm tra cache.\n- Viết test case kiểm chứng Cache Hit và Cache Miss.\n- Xử lý các tình huống đặc biệt như tham số null/rỗng và giá trị trả về null.\n\n## Hướng dẫn chạy chương trình\nChạy file chính bằng lệnh:\n```bash\npython main.py\n```
